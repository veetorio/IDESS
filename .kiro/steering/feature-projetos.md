Os projetos devem ser persistidos no banco de dados e renderizados no frontend.

Cada projeto deve conter logo (PNG, JPEG/JPG ou SVG), nome, descrição, quantidade de participantes informada pelo administrador, data de criação, pelo menos quatro fotos e o último evento associado. As fotos devem ser renderizadas na página de detalhes do projeto.

Eventos associados a projetos devem ter data de início e data de término. O status do projeto é calculado pelos eventos associados: "Em andamento" se pelo menos um evento estiver ocorrendo hoje; "Agendado" se ainda houver evento futuro; "Realizado" quando todos os eventos já tiverem terminado; e "Sem eventos associados" quando não houver eventos. Se um evento não for associado a um projeto, ele pertence ao Instituto.
